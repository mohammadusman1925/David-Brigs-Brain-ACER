# Course transcripts

The Ecomm Architects Copywriting Course V2, split one file per module. Verbatim — no cleanup,
no condensing, no rewriting.

These are the source. `mentor/david-brain.md` is a summary written from them, and the summary is
lossy. When the two disagree, or when you need David's actual phrasing, come here.

## What is here

27 files, one per module, named `NN-slug.md`. Modules 1, 3-16, 18-21, 23-30.

## The three anomalies, resolved

The Brain looked like it was missing Modules 2, 17 and 20, and like it used Module 22 twice.
Reading the source explains all four, and none of them were mistakes made by whoever wrote the
Brain.

**Module 2 — no recording.** The source is labeled "Transcript 2 (no file)." Nothing to capture.
Not a gap to fill.

**Module 17 — a duplicate of Module 16.** Transcript 17 is byte-for-byte identical to Transcript
16. Both open on open loops and curiosity gaps. There is no distinct Module 17 content, so only
`16-open-loops.md` exists. Not a gap to fill.

**Module 20 — it existed all along, mislabeled.** Transcript 20 is Handling Objections in Copy.
David opens it by saying "twenty-two, you are two-thirds of the way through," and whoever wrote
the Brain took him at his word and numbered the module 22. That produced both the apparent
missing Module 20 and the apparent duplicate Module 22. It is now corrected to Module 20 in the
Brain.

The running order confirms it. Module 19 signs off with "next up, we've got handling objections
in copy." Module 20 signs off with "next up is module 21, which is writing ad copy and video."

**Module 22 — no recording.** The source is labeled "Transcript 22 (no file)." The Brain's
Module 22 on advertorials and bridge pages was written from something other than a transcript,
and its numbering is correct. Module 23 opens by calling a VSL "an advertorial in video format,"
which places advertorials immediately before it, exactly where Module 22 sits.

## Using these

Read the transcript, not the summary, when you need:

- **How David actually talks.** This is the humanization standard. Varied sentence length,
  contractions, blunt asides. Any draft that sounds nothing like these is drifting.
- **The full version of something the Brain compressed.** The moat metaphor, the Formula One
  analogy, the Daily Virals self-test, the reasoning behind a case study.
- **A case study's real numbers and context**, rather than the one-line version.
